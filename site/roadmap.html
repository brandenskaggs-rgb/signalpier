THE PROJECT / OPEN FROM THE START

A radio desk
you can make your own.

SignalPier brings a small set of dependable tools into one interface. The application is MIT-licensed, its app installer is documented, and its limitations are visible.

BUILT WITH OPEN TOOLS

Credit where it's due.

Native receiver tools

RTL-SDR provides receiver utilities; rtl_433 provides protocol decoding. Their licenses remain separate from SignalPier's MIT license.

Maps and measurements

World geometry comes from public-domain Natural Earth. Space-weather observations come from NOAA SWPC.

A proven OS foundation

The application installs on an existing Raspberry Pi OS 64-bit system. SignalPier is an independent project, not an official Raspberry Pi product.
