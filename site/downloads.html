Download AppImage for Pi 3 ↓

Your download is one file: SignalPier-0.1.0-alpha.2-aarch64.AppImage. On the Pi, right-click the file, open Properties → Permissions, and allow it to execute as a program. Then double-click to open SignalPier. A menu shortcut is added on first launch.

Alpha release · 2026-11-07. Software tested under ARM64 emulation; physical Pi/receiver acceptance pending.

Runs on a Pi 3 with 64-bit Raspberry Pi OS desktop (Bookworm or newer). You can download it on Windows and copy it to the Pi; the AppImage runs on the Pi.

THREE SIMPLE STEPS

Get to your radio desk.

1. Download

Click the button above to save a single SignalPier AppImage.

2. Allow it to run

Right-click the file → Properties → Permissions → allow execution as a program. Linux requires this once for downloaded apps.

3. Double-click

Double-click the AppImage. Your dashboard opens and SignalPier is added to your applications menu for next time.
