THREE SIMPLE STEPS

Get to your radio desk.

1. Download

Click the button above in your Pi's browser. It downloads the application, not an operating system.

2. Install

Open the .deb file with your Pi's package installer. If an archive manager opens, close it and use Open With to select the software installer. It adds SignalPier and its receiver tools.

3. Open SignalPier

Launch SignalPier from the application menu, or open http://127.0.0.1:8765 on the Pi.

No graphical package installer? See the one-command installation option.
