# Contributing

Open an issue describing a reproducible problem or proposed feature. For receiver reports, include Pi model, 32/64-bit OS, receiver model, tool versions, and sanitized logs. Do not post passwords, keys, private messages, or precise personal locations.

Keep the Pi 3's 1 GB memory budget in mind. Prefer bounded native receiver jobs and browser rendering. Label synthetic data. Do not add unsupported device claims or promote an alpha to hardware-verified without reproducible physical acceptance results.

Run the tests documented in README.md. Keep application and website changes consistent, and update release notes for user-visible changes. Contributions are under the project's MIT license; preserve third-party notices.
